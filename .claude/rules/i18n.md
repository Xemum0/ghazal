# i18n (packages/i18n, design/src/i18n)

- Messages are flat ICU JSON: `messages/{en,ar}/<namespace>.json`, the two trees mirror exactly. Keys are camelCase and start with the camelCase namespace (`client-booking` -> `clientBookingReviewTitle`).
- New namespace: `node packages/i18n/scripts/new-namespace.mjs <app>-<flow>`; after adding or removing a file run `pnpm i18n:check --write`. Gate: `pnpm i18n:check` (warnings on length are advisory) and `pnpm -F @gz/i18n test`.
- Voice: ADR 0013 and `docs/design/content-guidelines.md`: native simplified Arabic with the honorific plural, verbal-noun CTAs, no exclamation marks, gender-neutral. The voucher is «كوبون» in Arabic (OQ-V-15).
- Numbers, money, dates, phones only through `GzFormat` / `useFormat()` (ADR 0010-0012). Never concatenate; use ICU placeholders and plurals.
- `common` and `*-shell` namespaces and `packages/i18n/src/**` belong to the copy-owner; a screen agent edits only its own namespace pair. `messages/allow.json` exceptions need a reason.
- Generated: `src/generated/namespaces.ts`. Do not hand-edit.
