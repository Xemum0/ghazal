# PRD – Ghazal (غزل)
## Wedding Venue Booking & Wedding Planning Platform
**Version:** 1.0 (MVP + Future Roadmap)

---

# Product Vision

Ghazal (غزل) is a premium wedding marketplace designed for Kuwait (later GCC) that allows couples to discover, compare, and book wedding venues while connecting them with every wedding-related service in one place.

Instead of searching Instagram, WhatsApp, and calling multiple venues manually, users can compare venues instantly, check availability, request bookings, and organize their entire wedding from one application.

The platform consists of four products:

1. Client Mobile App (iOS & Android)
2. Venue/Hotel Mobile App
3. Venue Admin Dashboard (Web)
4. Super Admin Dashboard (Owner)

---

# Main Goals

- Simplify venue booking.
- Reduce booking time.
- Help couples compare venues.
- Increase bookings for venues.
- Digitalize wedding planning.
- Become the Booking.com of wedding venues in Kuwait.
