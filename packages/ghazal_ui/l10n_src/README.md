# ghazal_ui l10n parts

`GzL10n` (packages/ghazal_ui/lib/l10n) is generated by `node tools/gen-l10n.mjs` from two sources:

1. `packages/i18n/messages/{en,ar}/common.json` (every shared word);
2. the component-owned parts in this folder: `<part>.en.json` and `<part>.ar.json`, one pair per component family
   (for example `gz-sheet.en.json` and `gz-sheet.ar.json` for the sheet's close label).

Rules for a part file: a flat object of key to ICU message, the same format and the same Arabic voice rules as
`packages/i18n/messages` (see packages/i18n/README.md). Keys are camelCase and start with `gz` plus the component (the one legacy exception is `stubNotBuilt`, used by `GzStubScreen`)
(`gzSheetClose`); they must not collide with a `common*` key, and the `en` and `ar` files hold exactly the same keys
and placeholders. Never type a digit in prose; use `#` in a plural or `{n, number}`.

After editing: `pnpm l10n` (merges, then runs `flutter gen-l10n`) and `pnpm l10n:check`. Do not edit
`lib/l10n/gz_*.arb` or `lib/l10n/generated/` by hand.
