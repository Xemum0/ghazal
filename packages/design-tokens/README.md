# @gz/design-tokens

Single source of every colour, space, radius, size, type, elevation, motion and icon value in Ghazal (ADR 0023, 0030, 0031). Single writer: the tokens owner (ADR 0029). Everyone else files a line in `docs/engineering/requests.md`.

```
src/tokens.json          DTCG-style source ($value / $type, reasons in $extensions.ghazal.reason). The only hand-edited file.
a11y-pairs.json          every allowed foreground/background pair + minimum ratio (the contrast gate's input)
scripts/build.mjs        generator + gates (in-house, about 850 lines across scripts/, no Style Dictionary: ADR 0023's documented fallback)
scripts/import-icons.mjs on-demand copy of the curated Phosphor subset (see Icons)
icons/                   manifest.json, <name>.svg (Light), regular/<name>.svg, brand/knot.svg, brand/divider.svg, LICENSE-phosphor.txt
dist/                    GENERATED, committed: tokens.css, tokens.ts, tokens.flat.json, icons.ts, index.ts, dart/gz_tokens.dart
```

Also generated by the same build: `design/src/styles/typography.roles.css` (one `.gz-t-<role>` class per type role).

## Commands (repo root)

```
pnpm tokens          write dist/ (and the role classes)
pnpm tokens:check    fail if dist is stale, or any gate fails; never writes
pnpm -F @gz/design-tokens contrast    print every measured pair (ratio, pass/fail)
```

Gates (all in `tokens:check`): token type allow-list; references resolve; raw colours only in `color.ref`; `space.N` on the 4-pt grid; control heights 44/48/52/56; AR/EN type key parity; even integer line heights, size at least 12; Arabic never tracked or uppercase; every role uses a shipped font weight (Poppins 400/500/600, Cairo 400-700, Newsreader 300/400, Amiri 400); Arabic display word spacing is -0.12 x size; icon manifest has a mirror flag per icon, every SVG is `<path>` only; contrast (text 4.5, UI 3) for 120+ pairs recomputed with the WCAG 2.x formula, each documented ratio within 0.02 of `docs/design/01-direction.md` 2.1, the recorded failing pairs must keep failing, gold rules (`color.sys.text.*` / `icon.*` may only resolve to gold-700, or gold-400/300 on dark; never gold-500).

## Naming (ADR 0023 D3)

Token path = dotted kebab segments. CSS: `--gz-` + path with dashes (`color.sys.text.primary` -> `--gz-color-sys-text-primary`). Two special cases: `font.<lang>.x` -> `--gz-font-x` and `type.<lang>.<role>.<prop>` -> `--gz-type-<role>-<prop>`, both switching under `:lang(ar)` (the AR block redeclares the family variables too, so a nested `lang` switch resolves correctly). Safe areas also get `--gz-safe-top` / `--gz-safe-bottom` (ADR 0024 D3). Dart: camelCase with `color.sys.` dropped (`GzColors.light.textPrimary`, `GzSpace.s4`, `GzSize.controlCta`, `GzMotion.durationSlow`, `GzType.forLocale(locale).body`).

| Namespace | Examples |
|---|---|
| `color.ref.*` | ink, gold (incl. 650 / 550), rose, neutral, success, danger, alpha. Hex lives only here. |
| `color.sys.*` | surface, text, icon, border, focus-ring, mark, action, control, status, scrim, shadow |
| `space.*` | 0..24 (x4 px), gutter 20, section 32, list-gap, shelf-gap, panel-pad |
| `size.*` | control sm/md/cta/lg = 44/48/52/56, touch-min, icon xs..lg, row, toggle, knot, avatar, thumb |
| `radius.*` `stroke.*` `z.*` | 4/8/12/20/9999; 1/1.5/2/4; 0..70 |
| `layout.*` | frame 390x844, safe top 47 / bottom 34, breakpoints 360/390/430, aspect ratios, hero heights |
| `elevation.*` `gradient.*` `shape.arch.*` | 0..3 shadows; photo scrims; the arch crown |
| `motion.*` | duration instant..success, ease standard/emphasized/exit/linear, spring settle, scale, distance |
| `font.*` `type.<en|ar>.<role>` | families; 39 roles (UI, display, figures, price, KPI...) per script |

## Using the outputs

- CSS: `design/src/shell/tokens.ts` loads `dist/*.css`; write `var(--gz-...)` in component CSS. Never `--gz-color-ref-*` outside this package.
- TypeScript: `import { tokens, flat, cssVar, icons, mirrorInRtl } from '@gz/tokens'`. `flat['space.4']` is `16`; `cssVar('space.4')` is `var(--gz-space-4)`.
- Dart: `dist/dart/gz_tokens.dart` (analyzed clean with Flutter 3.47; not run through `dart format`). Copy path into `packages/ghazal_ui` is a later step (ADR 0022/0023).
- Specs / redlines: `tokens.flat.json` maps every path to `{type, value, css, ref?, reason?}`.

## Icons

Source: Phosphor Icons `@phosphor-icons/core` 2.1.1 (MIT, `icons/LICENSE-phosphor.txt`), 127 product icons + 7 filled glyphs, named by product meaning (`search`, `pin`, `guests`, `compare`, `valet`, `back`). `icons/manifest.json` maps name -> Phosphor file, `mirror` flag and group.

- `dist/icons.ts`: `iconNames`, `icons` (the product weight), `iconsLight`, `iconsRegular`, `mirrorInRtl`, `isMirrored(name)`, `brand.knot`, `brand.divider`. Each glyph is `{ viewBox: '0 0 256 256', paths: string[] }`, `fill="currentColor"`. Render as `<svg viewBox fill="currentColor">` + one `<path>` per entry; add the `gz-mirror` class (base.css) when `isMirrored(name)`.
- Mirror list (ADR 0014 D2): back, forward, chevron-left/right, arrow-left/right, external-link, send, reply, undo, sign-in/out, menu, list, sort, checklist, notes, help. Never: play, phone, clock, check, search, heart, share, pin, bell, camera, charts, trends, logos.
- **Weight**: Light is canonical per the task, but its stroke is 12/256 = 1.125 px at 24, while `stroke.icon` and direction 2.6 say 1.5 px. Phosphor Regular (16/256) is exactly 1.5 px. Both are in the registry; `defaultWeight` in `icons/manifest.json` flips the `icons` export (one line, then `pnpm tokens`). Decision pending with the lead.
- Refresh: `npm i @phosphor-icons/core@2.1.1` in an empty scratch directory, run `node packages/design-tokens/scripts/import-icons.mjs <scratch>/node_modules/@phosphor-icons/core`, `pnpm tokens`. Phosphor is never a repo dependency.
- Brand: `knot.svg` is the 8 px diamond bead; `divider.svg` is a 1 px line ending in a knot (mirrors: it follows reading direction). The wordmark lockup is built from type tokens by the Wordmark component.

## Fonts

Self-hosted in `design/public/fonts` (woff2 + TTF twins for Flutter, OFL licences in `LICENSES.md`), declared in `design/src/styles/fonts.css`. Type roles reference families by token; weights are limited to the shipped files.
