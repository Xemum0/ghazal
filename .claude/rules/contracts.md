# Contracts and fixtures (packages/contracts, design/src/mock)

- Types and the pricing / availability / policy engine live in `src/`; authored bilingual data in `seed/*.mjs`; `fixtures/` is GENERATED by `pnpm -F @gz/contracts build` (never hand-edit). `design/src/mock` only re-exports.
- Gates: `pnpm contracts:check` = `build --check` (freshness) + `pnpm -F @gz/contracts validate` (about 16k checks, must be 0 errors, 0 warnings).
- Money is integer fils `{fils, currency}`; no floats. Every package and priced item carries a standard and a voucher price (ADR 0033 D4); a venue may approve at a lower voucher price, never higher (D3).
- Ad plan rates are undecided: no seeded listing carries an amount (OQ-V-07, OQ-V-17).
- Content follows `docs/design/seed-rulebook.md`: fictional venues, patterned phones and IBANs never clickable, no real brands, no faces, one value per fact.
- Voucher states: `unpaid, active, bound, used, expired, refunded`. Request statuses: `pending, approved, declined, expired, confirmed, redeemed, completed, cancelled` (ADR 0033 D2, D3).
