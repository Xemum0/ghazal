# Direction 03: The Thread (الخيط)

**Concept.** غزل is a love poem and a spun thread. One matte-gold line (2 px, round caps) is the signature, and it appears only when something is progressing, selected, connected or waiting.

**Memorable idea: the Booking Thread.** Request, approval, deposit, balance, day: five knots, seen identically by couple and hotel. Client side: stepper, status, payment schedule, countdown. Hotel side: the day's timeline and depleting reply windows. A knot ties only when something real happens.

**Colour.** Ink = text and the one dark surface. Gold-500 = fills and the thread; gold-700 (5.59:1) = gold text and icons; gold-600 = a lone stroke (3.53:1). Rose = tonal surfaces. Labels on gold use ink-950 (7.45:1). Green and red appear only for Paid and Declined, with icon and label.

**Type.** Poppins + Cairo only: a Light 300 sans is a monoline, like the thread. Cairo digits are the single numeric voice in both languages. Arabic = English × 1.08 to 1.10, with its own leading.

**Shape.** Radius 4 / 8 / 12 / 20 / 24 / pill. Tone, not shadow (sheet only). 4-pt grid.

**Motion.** 120 / 200 / 320 / 480 ms, thread draw 640 ms, two curves. The only loop is the loader.

**Risks.** The identity is motion, so static screens undersell it. Light type needs strong photography. Arabic Light below 26 px is thin. Gold-on-rose margins are small. Flutter needs one ThreadPainter and a per-span numerals formatter.
